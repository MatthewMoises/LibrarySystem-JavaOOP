# LibrarySystem-JavaOOP
Java Library Management System with login/signup, CRUD book operations, and sorting. Demonstrates OOP fundamentals.

A simple Java-based Library Management System with user authentication and book management features.
Built using Object-Oriented Programming (OOP) concepts and ArrayList.

✨ Features
🔑 User Authentication: Signup and login system with validation
📖 Book Management (CRUD): Add, remove, search, update, and display books
📚 Sorting: Books displayed in alphabetical order by title
🖥️ Console-based Interface: Easy to run and interact with

🛠️ Technologies Used
Java (OOP, Collections, Scanner input)
ArrayList for dynamic storage
Comparator for sorting

🎯 Learning Goals
This project demonstrates:
Java OOP fundamentals (classes, objects, encapsulation)
Basic authentication logic
CRUD operations
Console-based application design
